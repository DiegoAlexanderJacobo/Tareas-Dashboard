# Tareas Dashboard (Tablero)

Esta es una aplicación de gestión de requerimientos

## Instrucciones para levantar el entorno

El proyecto está  containerizado para facilitar su ejecución sin necesidad de instalar dependencias locales de Node.js.

**Requisitos previos:**
* Tener [docker](https://www.docker.com/) y docker compose instalados en tu máquina.

**Pasos para ejecutar:**

1. Se debe abrir una terminal en la raíz de este proyecto (donde se encuentra el archivo `docker-compose.yml`).
2. Ejecuta el siguiente comando para levantar el entorno:

```bash
docker compose up
